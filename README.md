# Teach-and-Repeat Robotic Arm — Arduino

A servo arm that can be taught a motion and repeat it. Potentiometers set each joint while you teach; a button switches to play mode and the arm replays the recorded positions. My first experience of "teaching a machine".

![Robotic arm](https://user-images.githubusercontent.com/105288469/187016819-5a6cbf21-2e55-46c3-9d8d-69ccc6dd9158.gif)

[Video of the arm](https://youtu.be/8QO0oT2Tb9E)

**Hardware:** Arduino · 4 servos (3-DOF arm + gripper) · potentiometers · push button — `Robotic_Arm_Arduino.ino`

**Where this led:** [3-DOF arm digital twin in ROS 2](https://github.com/MechaMind-Labs/ROS2_3DOF_Robotic_Arm_Digital_Twin) (same potentiometer idea, live in RViz/Gazebo) and my [SCARA conveyor cell](https://github.com/Curious-Utkarsh/ROS2_SCARA_WS).
